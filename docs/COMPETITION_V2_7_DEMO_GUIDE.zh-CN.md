# PixelFlow Desk AI v2.7.3 比赛演示与证据指南

## 本轮新增

v2.7.0 不再继续堆叠普通显示模式，而是补齐赛题最容易被追问的四类证据：

1. **真实端侧 AI**：ESP32-S3 直接完成五维特征提取、时序平滑、个性化分类和未知拒识。
2. **公平盲测**：模型锁定后禁止校准和主动学习，并隐藏预测；提交真实标签后才揭示结果。
3. **工程可靠性**：记录帧率、最低空闲堆、任务栈余量、复位原因和 Wi-Fi 断连次数。
4. **隐私与节能**：统计 App API 与天气联网请求，证明云端推理和原始传感数据上传均为零；同时对比节能模式与基线功率。

v2.7.2 修正 LDR 特征方向：桌面 AI 的环境光百分比现在随实际照度升高，并同步修正暗环境智能场景判断；已有个性化校准中心会在启动时自动迁移。正常光照下的主动倾斜现在优先触发流体，不再被音频保持时间或 AI 自动场景覆盖。

v2.7.3 修正规则智能场景状态机：使用相对姿态变化和陀螺仪检测主动操作，避免设备固定斜度持续误触发流体；增加音频确认时间和未完成 NTP 对时保护，并统一“计时、暗光/安静、姿态、音频、AI、手动”的场景优先级。

## 端侧判断链路

```text
MAX9814 + MPU6500 + LDR
        |
        v
五维特征 + 指数平滑
        |
        v
个性化原型分类 + INT8 对照 + 默认基线
        |
        +--> 低置信度或距离过大：Unknown
        |
        v
连续多帧确认后输出 Focus / Meeting / Rest / Away
```

未知拒识避免系统在证据不足时强行给出四选一答案；连续多帧确认降低瞬时噪声造成的状态抖动。

## 标准盲测流程

1. 关闭“排练数据”，确认 App 显示真实传感器数据。
2. 每类校准至少 4 次，建议 8 次；确认类别覆盖为 `4 / 4`。
3. 点击“锁定并开始盲测”。此时模型指纹固定，校准按钮和主动学习被禁用。
4. 让受测者进入一个状态，但不要先看设备预测。
5. 由评委点击真实标签。App 随后揭示个性化、默认基线与 INT8 结果。
6. 四类各采集至少 8 次，总样本建议不少于 32。
7. 点击“导出比赛证据包”，保存带版本、模型指纹、混淆矩阵和可靠性指标的 JSON 文件。

## 评委可现场验证

| 质疑点 | 现场验证 |
|---|---|
| 是否依赖云端 AI | 断开热点后状态识别仍运行，离线推理次数继续增加 |
| 是否边测边训练 | 锁定后校准和主动学习不可用，模型指纹保持不变 |
| 是否只挑成功样本 | 混淆矩阵、拒识次数与每类样本量全部导出 |
| 是否使用真实传感器 | 关闭排练数据，现场改变声音、姿态和光照，五维特征同步变化 |
| 是否稳定运行 | App 展示最低空闲堆、各任务栈余量、帧率、复位原因和断连次数 |
| 是否保护隐私 | 云端推理为 0、原始数据上传为 0；外部请求只用于天气和城市定位 |
| 节能是否有效 | 同屏展示当前功率、基线功率、瞬时节省和累计节电 |

## 建议展示顺序

1. 用 20 秒介绍设备端感知、App 交互和 32x8 显示闭环。
2. 用 30 秒展示模型锁定和一次现场盲测。
3. 用 20 秒展示个性化模型相对默认基线的准确率变化。
4. 用 15 秒展示断网推理、隐私联网审计和节能 A/B。
5. 最后导出证据包，说明所有结论都能复核。
